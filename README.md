# 星励 · 智学平台

一个面向中小学生的教育集成平台，采用可爱圆润的设计风格，整合了多种学习工具和游戏。

## 功能模块

- 早读检测仪：智能检测早读情况，提升学习效率
- 静学智能哨兵：智能守护学习环境，专注学习不干扰
- 成绩分析：多维度分析学习成绩，发现提升空间
- 星励成长积分系统：记录学习历程，激励成长进步
- 古诗检测：学习古诗词，感受中华文化魅力
- 水果单词消消乐：趣味英语学习，水果单词大挑战

## 技术栈

- React + TypeScript
- Tailwind CSS
- Framer Motion（动画效果）
- Lucide React（图标）
- Vite（构建工具）

## 快速开始

### 🚀 一键启动（推荐）

**Windows用户（最简单）：**
双击 `启动星励智学平台.bat` 文件即可一键启动星励智学平台！

**传统方式：**
双击 `start.bat` 文件

**命令行方式：**
```bash
node simple-start.js
```

一键启动器会自动完成以下操作：
1. 检查Node.js环境
2. 自动安装依赖（如果尚未安装）
3. 启动开发服务器
4. 显示访问地址

### 📋 高级启动选项

如果需要更多控制选项，可以使用完整版启动器：

仅检查环境，不启动服务器：
```bash
npm run check
```

仅安装依赖，不启动服务器：
```bash
npm run install-deps
```

使用特定端口启动：
```bash
node start.cjs --port 3000
```

启动但禁用自动打开浏览器：
```bash
node start.cjs --no-open
```

查看所有可用选项：
```bash
node start.cjs --help
```

### ⚙️ 传统启动方式

1. 手动安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run dev
```

### 💡 启动方式说明

- `启动星励智学平台.bat` - 最简单的方式，适合大多数用户
- `start.bat` - 传统启动方式，包含更多检查
- `simple-start.js` - 跨平台简单启动脚本
- `start.cjs` - 高级启动器，提供更多配置选项

## 设计特点

- **色彩方案**：莫兰迪绿(#8BA48B)作为主色调，低饱和黄色(#F0E68C)作为辅助色
- **布局设计**：三栏响应式布局，适配电脑、平板和手机
- **动画效果**：丰富的悬停动画和微交互效果
- **响应式设计**：完美适配各种设备尺寸
